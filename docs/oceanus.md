# 大洋之息 · 海洋生态模拟器 (oceanus)

> 分类: 模拟类
> Three.js 3D 海洋生态群系模拟 — Lotka-Volterra 种群动力学

## 世界规则

### 生态模型
- **种群动力学**: Lotka-Volterra 捕食-被捕食方程
- **能量传递**: 10% 营养级效率（Lindeman 法则）
- **光衰减**: Beer-Lambert `I(z) = I₀·e^(-kz)`
- **物质循环**: 碎屑→营养盐→浮游植物→浮游动物→鱼类→碎屑
- **环境承载量**: 每个营养级最大种群密度

### 生境 (Biomes)
| 生境 | 深度 | 物种数 | 特征 |
|------|------|--------|------|
| 珊瑚礁 | 0-200m | 高 | 高光/高温/高营养 |
| 开阔大洋 | 0-800m | 中 | 中等光/多变温度 |
| 深海 | 200-2000m | 低 | 低光/低温/高压 |
| 海藻林 | 0-400m | 高 | 中等光/温带 |
| 热液喷口 | 500-3000m | 特化 | 无光/高温热点/化学合成 |
| 极地海洋 | 0-1000m | 低 | 低温/季节性光照 |

### 物种属性
每个物种定义: `{ name, trophicLevel, size[min,max], speed, energyCap, lifespan, reproductionRate, diet, behaviors, environmentRequirements }`

### 昼夜循环
90 秒周期，光照强度 `0.5+0.5·sin(2π·time/dayLength - π/2)`

## 交互规则

| 操作 | 效果 |
|------|------|
| 点击生物 | 查看详情（物种/营养级/能量/大小/年龄/状态） |
| 点击空白 | 撒营养盐 |
| 右键拖拽 | 平移视口 |
| 滚轮 | 垂直平移 |
| Ctrl+滚轮 | 缩放 |
| 1-6 | 切换生境 |

### 键盘
| 键 | 功能 |
|----|------|
| 1-6 | 切换生境 |
| Space | 暂停/继续 |
| R | 重置 |
| F | 流线 |
| L | **双层空间切换** |

## 双层空间

| 层 | 名称 | 内容 |
|----|------|------|
| Layer 1 | 表象层 | 3D 渲染海洋生物、光照粒子、水纹效果 |
| Layer 2 | 结构层 | 2D 覆盖画布：营养盐浓度场热力图（绿）、光强分布（黄）、温度场（红）、碎屑浓度（棕）、网格线、统计标签 |

## 数据面板（右上角）
- FPS
- 活体生物数
- 总能量（生物质）
- 表层温度
- 平均营养盐 %
- 昼/夜指示
- 能量金字塔（左上角小画布）
