# 宏观力学 · 星空模拟器 (celestial-mechanics)

> 分类: 模拟类 | 模板项目
> 三维世界中 UI 布局、交互模式、视觉规则的参考基准。

## 世界规则

### 物理引擎
- **引力**: 牛顿万有引力 `F = G·M₁·M₂/r²`，G = 4π² ≈ 39.478 AU³/(M☉·year²)
- **积分器**: Verlet 式半隐式积分（position 用 current velocity，velocity 用 new acceleration）
- **碰撞**: 半径叠加判定，非弹性碰撞合并，合并后半径 ∝∛mass
- **相对论修正**: 后牛顿近似 → 进动效应（弱场极限），引力透镜（背景星场偏折）

### 单位体系
| 量 | 单位 | 换算 |
|----|------|------|
| 质量 | M☉ (太阳质量) | 1 M☉ = 1.989×10³⁰ kg |
| 距离 | AU (天文单位) | 1 AU = 1.496×10⁸ km = 50px |
| 时间 | year | 1 year = 2400 timesteps |

### 场景预设
1. **太阳系** — 8 行星 + 太阳，稳定轨道
2. **双星** — 双星互绕 + 行星
3. **星团** — 50 颗随机质量天体
4. **旋涡** — 旋涡星系初始条件
5. **碰撞** — 两群星团对撞
6. **混沌** — 高度不稳定 N 体
7. **三体** — 经典三体问题
8. **黑洞** — 超大质量黑洞 + 星团

### 守恒监控
每个天体有能量标签：KE=½mv², PE=-GMm/r，UI 显示总能量，守恒误差 < 1%。

## 交互规则

| 操作 | 效果 |
|------|------|
| 点击空白 | 放置当前选中天体 |
| 拖拽 | 放置 + 弹射初速度（反方向） |
| 右键天体 | 消除 |
| Shift+拖拽 | 平移视口 |
| 滚轮 | 以鼠标位置为中心缩放 |
| 双击 | 重置视角 |

### 键盘
| 键 | 功能 |
|----|------|
| 1-8 | 切换场景 |
| G | 力场网格 |
| T | 轨道痕迹 |
| F | 引力线 |
| E | 相对论效应 |
| L | **双层空间切换** |
| R | 重置场景 |
| C | 清空天体 |

## 双层空间

| 层 | 名称 | 内容 |
|----|------|------|
| Layer 1 | 表象层 | 可见星体、轨道、辉光、碰撞、引力透镜 |
| Layer 2 | 结构层 | 引力势场热力图（暖色=深势阱）、速度矢量箭头（大小+方向）、天体轮廓线+质量标签、势场图例 |
