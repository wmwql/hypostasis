## 一、世界规则

### 1.1 核心原则 —— 可观测、可量化、可计算

模拟类项目的一切行为必须基于**基本物理/生态规律**，不允许凭空造物。

| 原则 | 说明 |
|------|------|
| **可放置** | 用户可以在空间中放置实体（天体、粒子、生物） |
| **可量化** | 每个实体有可测量的属性：质量、速度、能量、生命周期 |
| **可计算** | 所有行为由微分方程/数值积分驱动，结果是确定的 |
| **可观测** | 实时数据显示：FPS、实体数、能量总和、种群密度 |

### 1.2 物理法则（按项目分层）

```
┌──────────────────────────────────┐
│  Layer 1: 表象空间 (Observable)    │
│  - 星体位置/轨道/碰撞             │
│  - 粒子运动/堆积/流动             │
│  - 生物游动/捕食/繁殖             │
├──────────────────────────────────┤
│  Layer 2: 结构空间 (Structure)    │
│  - 引力势场 / 速度场              │
│  - 流体速度 / 温度 / 营养网格     │
│  - Lotka-Volterra / Beer-Lambert  │
└──────────────────────────────────┘
```

#### 天体力学 (celestial-mechanics)
- **引力**: 牛顿万有引力 `F = G·M₁·M₂ / r²`，G = 4π² (AU³/(M☉·year²))
- **N 体积分**: Verlet / RK4 积分器
- **碰撞检测**: 半径叠加判定，非弹性碰撞合并质量
- **守恒律**: 总能量(动能+势能)守恒监控
- **单位体系**: M☉(太阳质量) / AU(天文单位) / year

#### 粒子沙盒 (god-sandbox)
- **重力**: `g = 12 px/s²` 向下，受流体浮力调制
- **流体网格**: Navier-Stokes 简化 —— 速度扩散 + 压力梯度 + 连续性方程
- **粒子分类**: 沙(堆积)、岩石(固定)、水(扩散)、营养盐(扩散+衰变)、光子(向上漂浮)
- **相互作用**: 水灭火/溶解营养盐、光子触发光合作用、沙堵水

#### 海洋生态 (oceanus)
- **种群动力学**: Lotka-Volterra 捕食-被捕食方程
- **能量传递**: 10% 营养级效率 (Lindeman 法则)
- **光衰减**: Beer-Lambert `I(z) = I₀·e^(-kz)`
- **物质循环**: 碎屑→营养盐→浮游植物→浮游动物→鱼类→碎屑
- **环境承载量**: 每个营养级有最大种群密度

### 1.3 量化要求

每个模拟项目必须暴露以下量化指标：

| 指标 | celestial-mechanics | god-sandbox | oceanus |
|------|---------------------|-------------|---------|
| FPS | ✓ | ✓ | ✓ |
| 实体数 | 天体数 | 粒子数 | 生物数 |
| 能量 | 总动能+势能 | — | 总生物质 |
| 分项统计 | 质量分布 | 沙/水/光计数 | 营养级分布 |
| 场量 | 引力场强 | 流速/温度 | 营养盐浓度 |

## 四、双层空间架构

### 4.1 概念

每个模拟项目维护两个并行的空间层：

```
Layer 1 — 表象层 (Manifest Layer)
  用户直接观察和交互的空间。
  渲染：星体、粒子、生物等可见实体。
  交互：放置、拖拽、消除。

Layer 2 — 结构层 (Structure Layer)
  驱动表象层的底层物理场。
  渲染：力场热力图、速度矢量箭头、密度网格。
  交互：只读观察，不可修改。
```

### 4.2 切换机制

- **按键**: `L` 键切换
- **视觉反馈**:
  - 切换时画面有 0.3s 的交叉淡化过渡
  - 左上角出现层级指示器: `表象` / `结构`
- **Layer 2 渲染内容**:

| 项目 | Layer 2 渲染 |
|------|-------------|
| celestial-mechanics | 引力势场热力图 + 速度矢量 + 拉格朗日点标记 |
| god-sandbox | 流体速度网格 + 温度/营养场 + 压力分布 |
| oceanus | 营养盐浓度场 + 光强分布 + 能量金字塔 |

### 4.3 Layer 2 视觉风格

- 半透明热力图覆盖 (红=高值, 蓝=低值)
- 细线绘制网格边界
- 小箭头表示场方向
- 所有 Layer 2 元素使用 `globalAlpha = 0.4-0.7`
- Layer 1 实体在 Layer 2 视图中以轮廓线显示
