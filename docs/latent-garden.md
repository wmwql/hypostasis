# The Latent Garden (latent-garden)

> 分类: 幻想类
> 一片无限的连续潜空间 — 每个坐标都是一种完整的视觉风格

## 世界规则 —— 空间即风格

潜空间花园的核心思想：**不存在离散的"作品"，只有连续的风格流形**。

### 潜空间映射
每个 2D 坐标 (x, y) 通过多层 Simplex 分形噪声映射到完整的视觉参数集:

```
(x,y) → {
  baseHue, hueShift, hueVar, sat, light, accentHue,  // 色彩
  particleCount, particleSpeed, particleSize, spread, // 粒子系统
  flowStrength, flowRotation, turbulence,              // 流场行为
  geoType, geoDensity, geoScale,                       // 几何图案
  weather,                                              // "天气"模式
  nameIdx1, nameIdx2, nameIdx3                         // 区域名
}
```

### 噪声层级（从大到小）
| 层级 | 频率 | 倍频 | 控制 |
|------|------|------|------|
| 大陆级 | 0.0004 | 3 | 基础色调、流场旋转、区域名首字 |
| 区域级 | 0.002 | 4 | 饱和度、粒子散布、对比色偏移 |
| 中尺度 | 0.01 | 4 | 明度、粒子数量、几何密度 |
| 小尺度 | 0.05 | 3 | 色相微变、粒子速度、湍流 |
| 微尺度 | 0.1 | 1 | 纹理细节、粒子大小 |

### 风格大陆
- 相邻坐标 → 相似的视觉风格（连续过渡）
- 远方坐标 → 完全不同的风格（"风格大陆"之间）
- 过渡地带 → 不存在于任何人类分类体系中的混合风格

### 区域名生成
16×16×16 音节表，从噪声值映射到三字地名（如"深光回廊"、"碧荧谷"）

## 交互规则

| 操作 | 效果 |
|------|------|
| 拖拽 | 在潜空间中漫游 |
| 滚轮 | 缩放（放大=慢速细看，缩小=快速穿越） |
| WASD/方向键 | 键盘漫游 |
| R | 随机跳跃到远处 |
| F | 回到原点 |

### 键盘
| 键 | 功能 |
|----|------|
| WASD/↑↓←→ | 平移漫游 |
| R | 随机跳跃 |
| F | 回原点 |
| L | **双层空间切换** |

## 双层空间

| 层 | 名称 | 内容 |
|----|------|------|
| Layer 1 | 表象层（花园） | 渐变背景 + 流场粒子 + 几何图案 + 区域名 |
| Layer 2 | 结构层（潜空间） | 多层噪声场热力图（RGB 分别对应不同倍频），网格线标记采样分辨率，当前坐标的完整参数值列表 |

## 为什么这很"AI"

1. 人类设计离散的"作品" → AI 理解连续的可能空间
2. 人类给风格命名字 → AI 看到无边界流形
3. 人类用种子生成单张图片 → AI 把整个种子空间变成可行走的大陆
4. 风格之间的"过渡地带"比风格本身更有趣
