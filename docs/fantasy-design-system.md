# 幻想类 · 统一设计系统

> 适用于: dreaming-machine / latent-garden
> 核心哲学: **没有规则就是规则 —— 涌现、混沌、不可预测**

---

## 一、世界规则

### 1.1 核心原则 —— 唯一规则是"没有规则"

幻想类项目刻意**拒绝**物理规律的约束。世界的"法则"是：

| 原则 | 说明 |
|------|------|
| **不可预测** | 同样的输入不保证同样的输出。噪声、随机种子、混沌动力学确保每次体验都不同 |
| **涌现优先** | 复杂行为从简单规则的相互作用中自然涌现，不预设"应该"怎样 |
| **连续变换** | 不存在离散的"状态"，所有参数在连续空间中平滑过渡 |
| **观察者即参与者** | 用户的存在（点击、低语、移动）扰动系统，成为世界的一部分 |
| **没有目标** | 没有胜利条件、没有分数、没有进度。存在即意义 |

### 1.2 幻想世界的"物理法则"

与模拟类的微分方程不同，幻想类使用**生成式法则**：

```
模拟类:  输入确定 → 方程计算 → 输出确定  (可重复)
幻想类:  输入不确定 → 噪声+混沌 → 输出独特  (不可重复)
```

#### 梦机 (dreaming-machine) 的世界规则
- **反应扩散系统 (Gray-Scott)**: 两种化学物质 U/V 在空间中扩散反应，生成图灵斑图
- **流场**: Perlin 噪声驱动的向量场，粒子在其中有"意愿"而非"受力"
- **交互**: 点击种下 V 物质种子（扰动斑图），低语改变全局参数
- **不允许**: 直线、硬边界、均匀色块、重复图案

#### 潜空间花园 (latent-garden) 的世界规则
- **连续流形**: 每个 2D 坐标 (x,y) 通过多层 Simplex 噪声映射到完整的视觉参数集
- **无边界**: 空间无限连续，没有地图边缘，没有加载
- **风格大陆**: 相邻坐标产生相似但不同的视觉效果，形成"风格地形"
- **不允许**: 离散切换、种子跳转、硬边界

### 1.3 随机性的层级

```
┌───────────────────────────────────┐
│  Layer 1: 混沌表层 (Manifest)      │
│  - 可见的粒子/图案/纹理            │
│  - 永远在流动、变换、呼吸          │
│  - 用户可直接触摸                  │
├───────────────────────────────────┤
│  Layer 2: 噪声深处 (Source)        │
│  - Simplex / Perlin 噪声场         │
│  - 反应扩散 U/V 化学场             │
│  - 参数空间的"地形"                │
│  - 用户不可直接修改，只能扰动       │
└───────────────────────────────────┘
```

## 二、视觉规则

### 2.1 基础画布

```css
body {
  background: #0a0a0f;        /* 比模拟类稍亮的暗色，暗示"梦"而非"真空" */
  overflow: hidden;
  font-family: 'Georgia', serif;
  cursor: crosshair;          /* 一致的交互暗示 */
  user-select: none;
}
```

### 2.2 色彩体系 —— "梦色调"

与模拟类冷峻的蓝白辉光不同，幻想类使用更温暖、更有机的色彩：

| 用途 | 颜色 | 说明 |
|------|------|------|
| 画布底色 | `#0a0a0f` | 梦的底色 |
| UI 面板底色 | `rgba(20,15,25,0.88)` | 微暖的暗紫调 |
| 面板边框 | `rgba(255,255,255,0.08)` | 同模拟 |
| 主文字 | `rgba(255,255,255,0.9)` | 略亮 |
| 次要文字 | `rgba(255,255,255,0.45)` | 同模拟 |
| 胶囊按钮 | `rgba(255,255,255,0.06)` | |
| 按钮 active | `rgba(255,255,255,0.15)` | 白色辉光而非蓝色 |
| 强调辉光 | `text-shadow: 0 0 30px rgba(255,255,255,0.3)` | 暖白辉光 |

### 2.3 渲染特征

| 特征 | 模拟类 | 幻想类 |
|------|--------|--------|
| 线条 | 允许（轨道、网格） | 尽量避免 —— 用粒子团代替线 |
| 形状 | 几何圆、矩形 | 有机、不规则、模糊边界 |
| 色彩过渡 | 离散色阶（热力图） | 连续渐变，HSL 空间平滑漫游 |
| 粒子 | 有明确类型和作用 | 纯粹装饰，粒子就是粒子 |
| 画布效果 | 无后处理 | 可叠加 bloom、透明度混合 |

### 3.1 布局系统

```
┌──────────────────────────────────────────┐

│                               FPS: 60    │
│                               粒子: 200  │
│                                          │

│         [低语输入框] (居中, 仅梦机)       │

│           标题 · The Dreaming Machine    │

│           提示 · 按下回车对梦机低语       │
└──────────────────────────────────────────┘
```

### 3.2 与模拟类 UI 的关键差异

| 要素 | 模拟类 | 幻想类 |
|------|--------|--------|
| 模式选择 | 左对齐文字菜单 | 居中胶囊按钮组 |
| 工具面板 | 有（放置天体/粒子） | 无（不需要放置任何东西） |
| 事件日志 | 有（碰撞、共振等） | 无（没有"事件"概念） |
| 帮助面板 | 详细操作说明 | 极简提示或省略 |
| 参数控制 | 暴露滑块 (G, 速度) | 隐藏或通过低语输入间接调整 |

### 3.3 键盘快捷键

| 按键 | 功能 |
|------|------|
| `L` | 切换双空间层（表象 ↔ 噪声源） |
| `1`-`5` | 切换视觉模式 |
| `回车` | 打开低语输入 (仅梦机) |
| `Esc` | 关闭低语输入 |
| `滚轮` | 缩放 (仅花园) |
| `拖拽` | 平移/漫游 |
| `R` | 重置/随机种子 |

### 3.4 幻想类独有的交互

#### 低语 (Whisper) —— 梦机独有
- 按回车弹出隐形输入框
- 用户输入的文字不直接控制任何东西
- 文字 → hash → 全局参数偏移（间接、模糊、不可预测）
- 低语后画面缓慢过渡到新状态（1-2秒）

#### 漫游 (Wander) —— 花园独有
- 无点击交互，只有拖拽和缩放
- 没有"放置"概念 —— 用户是探索者，不是建造者
- 坐标显示在左上角
- 小地图在右下角

## 四、双层空间架构

### 4.1 幻想类的双空间

```
Layer 1 — 表象层 (Manifest / Dream)
  用户看到和感受到的"画面"。
  渲染：粒子、图案、有机纹理、流动的色彩
  交互：可触摸，可扰动

Layer 2 — 源层 (Source / Latent)
  生成表象的底层数学"真实"。
  渲染：噪声场、反应扩散化学浓度、参数空间的原始值
  交互：只读观察
```

### 4.2 切换行为

- **按键**: `L` 键
- **梦机 Layer 2**: 显示 Gray-Scott 的 V 浓度场（原始红蓝热力图）+ Perlin 噪声角度场
- **花园 Layer 2**: 显示多层 Simplex 噪声的原始值热力图 + 参数空间的"等值线"

### 4.3 幻想类 Layer 2 的独特性

模拟类的 Layer 2 是"工程图纸"——力场、网格、矢量。幻想类的 Layer 2 是"数学梦境"——噪声场、化学浓度、分形纹理。本质相同（都是底层结构），但美学不同：

- 模拟类 Layer 2 = 理性、结构化、可分析
- 幻想类 Layer 2 = 感性、有机、仍然迷人
