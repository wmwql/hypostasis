# The Dreaming Machine (dreaming-machine)

> 分类: 幻想类
> 一幅活的画布 — 反应扩散 + 流场粒子 + 集群生命共存共生

## 世界规则 —— 没有规则

梦机刻意拒绝确定性。三条生成系统在同一画布上交织，互相扰动，形成永不重复的视觉体验。

### 三大生成系统

#### 1. 反应扩散系统 (Gray-Scott)
- 两种化学物质 U(养料) 和 V(形素) 在 200×120 网格上扩散反应
- 方程: `∂U/∂t = Du·∇²U - UV² + feed·(1-U)`, `∂V/∂t = Dv·∇²V + UV² - (feed+kill)·V`
- 参数在"混沌边缘"附近微调（feed≈0.04-0.065, kill≈0.055-0.067）
- 产生: 珊瑚纹、豹纹、指纹、迷宫等图灵斑图

#### 2. Perlin 流场
- 3 倍频 Perlin 噪声叠加生成方向场
- 粒子在流场中漂移，速度受场强度和湍流参数调制
- 流场随时间缓慢旋转演化

#### 3. 集群生命 (Flocking)
- 类 Boids 算法: 凝聚 + 对齐 + 分离
- 每个"生命"在画布上游走，留下发光尾迹
- 受 RD 场调制 → 在 V 浓度高处聚集

### 混沌边缘
系统定期（~12-25秒）重置 RD 场并微调参数，确保永远不收敛到稳定态。自动模式下参数随机游走，避免任何重复。

## 交互规则

| 操作 | 效果 |
|------|------|
| 点击/拖拽 | 种下 V 形素种子（扰动斑图）|
| 移动鼠标 | 留下火花尾迹，光标带光晕 |
| 回车 | 打开"低语"输入 |
| 低语文字 | 文字→hash→全局参数偏移（间接、模糊） |

### 模式切换（居中胶囊按钮）
| 模式 | RD 参数 | 视觉效果 |
|------|---------|----------|
| 自动交融 | 随机游走 | 不断变换 |
| 珊瑚秘境 | feed=0.0545, kill=0.062 | 珊瑚纹 |
| 神经风暴 | feed=0.04, kill=0.058 | 迷宫/神经网络纹 |
| 深空宇宙 | feed=0.06, kill=0.065 | 星云状 |
| 星辰低语 | feed=0.05, kill=0.06 | 细腻纹理 |

### 键盘
| 键 | 功能 |
|----|------|
| Enter | 打开低语 |
| Esc | 关闭低语 |
| L | **双层空间切换** |

## 双层空间

| 层 | 名称 | 内容 |
|----|------|------|
| Layer 1 | 表象层（梦） | 彩色 RD 图案背景 + 流场粒子 + 集群生命 + 火花 |
| Layer 2 | 结构层（源） | 原始 V 浓度场热力图（红=V形素, 蓝=U养料），Perlin 流场方向网格（白线），RD 参数值显示 |
